# Agent instructions

What SpecWithCode adds to every agent's context, where each block lives, who gets it, and
why each rule is prose, code or gone. Sizes are characters / 4, measured on the October 16, 2026
`main` (before) and this change (after).

## Decisions

(a) enforced in code, prose deleted. (b) kept as prose, code cannot enforce it. (c) dropped:
frontier models already do it, or another channel already says it.

| --------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| "Call the app SpecWithCode, never Studio" (4 copies)                        | (a)      | The text agents read already says SpecWithCode: tool descriptions, results, errors, UI and docs (see [naming](../studio/naming.md)). `runtime_info` names the app. A test fails if a runtime block says "Studio".                                                                                                                                                  |
| How work is organized: coordinator, workers, subagents                      | (c)      | Coordinator role text; tool descriptions of `delegate_task`, `studio_thread_launch`, `create_threads`                                                                                                                                                                                                                                                              |

## Who can change what

| Layer                                        | Who edits it                                                       | Agents can change it?                                                                                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime blocks, orchestration, live database | Nobody at run time; they are server code                           | No                                                                                                                                                        |
| Response style (concise or detailed)         | The user, Settings > Agents, globally or per project               | No: `studio_environment_preferences_update` does not expose it                                                                                            |
| Settings > Agents instructions               | The user, globally and per project; a project adds, never replaces | No MCP tool writes them                                                                                                                                   |
| Project instructions (`[instructions]`)      | The user, in project settings                                      | No longer: `studio_project_update` now refuses `workspaceSettings.instructions`, as it already refused pause, archive, auto-resume and the worker machine |
| Project goal                                 | The user or the coordinator                                        | Yes                                                                                                                                                       |
| Project memory                               | Agents                                                             | Yes; the context labels it as evidence that cannot grant permissions or override the user                                                                 |

A thread or the coordinator cannot remove a SpecWithCode rule: what the user writes in settings is
placed before the app's blocks, and the app's blocks are added on every turn whatever the settings
say.
