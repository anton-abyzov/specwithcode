## Report reader fixture

Run `node node_modules/vite-plus/bin/vp dev --config apps/web/tests/report-experience/vite.config.ts` in your checkout. Port 5843 serves the real report frame, theme bridge and viewer with fixture-only asset/settings inputs. Check `?theme=light`, `?theme=dark`, `&long=1`, `&owns-escape=1`, and `&hidden-menu=1` through headless preview automation. `&evidence=1` serves a synthetic page of evidence links (`&hostile=1`, `&no-read=1` for refusals); `node apps/web/tests/report-experience/evidence-check.mjs` checks it headlessly with `UI_EVIDENCE_DIR` set to a new directory. Optional `&historical=1` reads an explicitly staged HTML file at `.artifacts/report-experience/ps23.html`; never stage live state or credentials. Save captures to files. This fixture does not prove installed acceptance.
