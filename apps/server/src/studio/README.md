# Native capacity boundary

GET reads only the same machine's Switch at `127.0.0.1:8318` and cached configured native provider snapshots. Opening the overview performs no provider refresh, login or inference. Explicit authenticated Refresh forwards only an empty structured body. Policy and account pin control future Switch work; Studio starts through an explicit actual provider instance and does not replace a running conversation. Automatic quota-aware cross-account migration is unsupported.

Default and exact canonical isolated native homes bind only when current settings, actual enabled provider, fresh supported native authorization and Switch profile agree. Unmapped custom Claude homes remain unverified until supported independent consumer sign-in can prove isolation. Explicit API/managed instances are a separate lane, excluded from subscription capacity. Inherited API routes/credentials and copied OAuth overrides are neutralized only at consumer native launch boundaries; generic drivers retain ordinary inheritance.

Switch is optional for deliberately selected native instances that already have fresh supported native authorization. Available Switch facts still block known exhaustion, busy profiles, unsigned profiles and legacy OAuth. Missing optional capacity never manufactures a recommendation or authorizes an unknown native profile.

Only Codex's supported `account/rateLimits/read.accountId` establishes a pool: the server hashes it ephemerally and publishes only `codex:sha256:<digest>` plus its own observation time. Quota notifications preserve that time; a separate 15-minute freshness bound prevents old identity reuse. Missing identity remains unknown. Partial verified pool counts are not total subscriptions and profiles with equal quota values are never merged.

All mutation bodies reject unknown fields. Environment auth and operate scope are required; browser mutations additionally require an exact same-host or explicitly trusted desktop/private origin (HTTPS forwarded protocol supported, forwarded host never trusted). Transport redirects, arbitrary URLs, raw native errors, account emails and credentials are not exposed.

Codex admission re-reads supported effective `config/read` for the actual session cwd and rejects custom provider, forced API and endpoint/auth overrides. A global route observation cannot authorize another project; quota ticks never renew its timestamp. See [BOUNDARY.md](./BOUNDARY.md) for the full routing contract.
