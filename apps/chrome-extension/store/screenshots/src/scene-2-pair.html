SpecWithCode Browser

Pair in three steps

  1. In the SpecWithCode app, open Settings › Chrome and copy the pairing code.
  2. Click the extension icon and paste the code.
  3. Name this Chrome profile, for example Personal or Work, and click Pair this profile.

The code only works for SpecWithCode on this computer: the extension refuses any address that is not a loopback address such as 127.0.0.1.
