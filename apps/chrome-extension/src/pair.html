Pair this Chrome profile with SpecWithCode

Agents you run in SpecWithCode will use this profile, signed in as you, on this computer only.

Copy the code from SpecWithCode: first-run setup, or Settings > Chrome.

Give it a name agents can tell apart, then press Enter or Pair.

Connecting…

Agents see only this Chrome profile, and only while it is paired. Tabs they use sit in the blue SpecWithCode tab group; drag a tab out of it to take it back. The toolbar icon shows ON while agents can use this profile.
